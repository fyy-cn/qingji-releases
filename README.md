清记支持微信/支付宝支付候选通知记账、账单导入、手动补记、自定义消费分类、日周月年分析、CSV导出和口令加密备份。账本存储在本机，联网仅用于版本检查和用户确认后的安装包下载。

已有旧版请直接覆盖安装，不要卸载。打开应用自动检查新版，后台每天定期检查；安装时由系统确认。系统省电和离线可能延迟检查，设置中可手动检查。

本仓库只保存公开下载页与版本资料，不包含应用私钥、用户账单、支付通知或备份，也不包含 Android 应用源码。APK位于 Releases；版本清单位于 `docs/releases/latest.json`。

通知识别依赖手机实际收到的内容，可能遗漏；请定期导入账单核对。当前为测试版，真机自动采集覆盖和后台行为需持续验证。
