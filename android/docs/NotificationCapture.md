# 通知采集、连接恢复与交我办（1.7.1）

已有清记请覆盖更新，不要卸载。账本、分类与模板沿用原数据，数据库4、备份格式5保持不变。

## 一段时间后停止采集的修复

旧逻辑在断开后只请求一次重连，进程在后台时缺少持续恢复；状态依赖内存中的服务引用，补读失败时也可能仍显示已连接。本版针对这些代码缺口处理，不将其直接认定为小米手机的唯一根因。

- 断开或服务销毁后请求重连；未连接时按10秒、30秒、1分钟、5分钟退避，之后最多每5分钟继续尝试（进程存活期间）。连接成功取消后续重试，避免反复打断健康监听。
- 返回前台、后台周期任务会检查现有服务；空通知列表是正常情况，读取返回null或异常时才清理失效连接标记并重连。不把“很久没消费”当成掉线。
- 独立的WorkManager周期任务按15分钟最小周期检查，不需要网络、不要求电量不低，也不受“后台检查更新”开关影响。周期不是准点承诺，系统休眠、省电和厂商限制可能推迟执行。
- 应用进程启动、手机正常开机完成和覆盖更新后尝试恢复已授权监听。新增普通开机广播权限，没有新增通知内容权限或常驻前台服务。
- 撤销通知使用权后不请求绑定、不补读，停止进程内重试；下次打开应用也会取消已安排的后台检查。不会自行授予或重新开启系统权限。
- 重新连接后补读仍在通知栏中的支持来源，保留原分类、备注与去重流程。已经清除的通知无法补回，需要导入账单或手动补记。

设置中的“最近连接检查”“后台检查”和“连接恢复中”帮助区分连接问题与通知解析问题；复制诊断另含恢复触发原因、次数和下次重试时间，不含交易内容。

手机若执行“强行停止”，请先重新打开清记。小米后台自启动和省电设置仍由你控制，见[小米说明](Xiaomi.md)。本版没有在小米Android16真机完成长时间锁屏验证，自动测试覆盖模拟断线、回收和重启/更新广播。

参考：[Android通知监听生命周期](https://developer.android.com/reference/android/service/notification/NotificationListenerService)、[周期任务及系统调度限制](https://developer.android.com/develop/background-work/background-tasks/persistent/getting-started/define-work)。

## 通知栏有支付通知，但清记没有记录

1. 打开清记 → 设置 → 自动记账，查看“通知使用权”和“通知监听”。系统授权与服务实际连接是两种状态。
2. 已授权时点“重连并补读当前通知”，等待系统连接。服务连接后会尝试补读仍保留在通知栏中的支持来源通知。打开清记也会请求恢复连接；不会自动授予权限。
3. 查看最近通知结果和待确认账单。回调/补读次数包含重复补读，识别/补全次数也不代表账单笔数；重复事件由账本去重。
4. 仍无记录时复制“通知诊断”反馈。它区分未连接、没有收到、空正文、普通聊天过滤、非交易内容、分组汇总、待核实或已识别。内容只包含版本、连接状态、字段名称、字符数、结果代码和计数，不包含原始通知标题、正文、金额、商家或订单号。

已清除的历史通知无法从当前通知栏补读；微信/支付宝可用账单导入补齐。学校账单导入格式尚未适配，可手动补记。诊断能缩小故障范围，不代表已证明小米Android16上的具体根因。

1.5.0支持从通知标题、副标题、会话标题及消息样式的发送方查找微信支付服务标识，读取标准正文、展开正文、文本行与消息条目。普通聊天仍不会仅因正文出现“微信支付”而入账。成功支付附带优惠券宣传不再被一律丢弃。系统未向监听服务提供的文字无法恢复。

## 选择交我办

1. 设置 → 校园应用 · 交我办 → 选择交我办。
2. 从已安装且有桌面入口的应用中搜索“交我办”，核对名称和包名后选择。应用列表仅用于本机选择，不上传；不需要学校账号或密码。不同学校版本通过实际安装的包名区分。
3. 保持通知使用权开启。所选学校应用的交易通知会尝试生成候选，来源显示“校园 / 交我办”，新记录先待确认，核实后才计入消费。
4. 如果学校应用不发交易通知，可选开启“支付页面识别（实验）”，在交我办手动打开一笔已有消费详情。它只尝试读取系统提供的可访问文字，不会自行登录、查询学校后台、点击付款、截图或读取App私有数据库。
5. 可点“停止采集校园应用”。不删除历史账单；之后不再接收该应用的新候选。更换应用后只采集当前选择的一个校园应用。

校园页面需要消费详情/消费成功等标题、支出或消费类型依据，以及明确标注的消费金额或商户字段。余额不会用作消费金额；金额缺失时提示核对。通知中的充值作为转账类候选，默认不计入消费；页面识别排除充值、退款、转账等非消费模板。

本次未取得真实交我办交易样例，也未连接手机，因此学校版本是否提供通知/文字、字段模板是否匹配仍需验证。学校通知不包含商家、页面不提供文字时，不能凭空还原商家；分类继续使用本地商家规则和关键词推荐，可在确认时修改。

## 更新与备份

1.6.0的加密备份格式5包括校园渠道账单、分类、规则与场景模板，仍可读取格式1至4的旧备份。旧版清记不支持新版备份，请保留升级前备份。通知/页面权限和所选校园App不进入账本备份，恢复后需重新选择并授权。CSV可导出校园渠道，完整恢复请使用加密备份。

1.7.0可用[快捷归类](QuickClassification.md)整理已采集记录。只需分类，其他信息可放备注，归类不要求开启页面实验，也不会自动确认金额或类型尚不明确的记录。
