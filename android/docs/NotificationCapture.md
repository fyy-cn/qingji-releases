# 通知采集与交我办（1.5.0）

已有清记请覆盖更新，不要卸载。账本、分类与规则沿用原数据，数据库仍为版本3。

## 通知栏有支付通知，但清记没有记录

1. 打开清记 → 设置 → 自动记账，查看“通知使用权”和“通知监听”。系统授权与服务实际连接是两种状态。
2. 已授权时点“重连并补读当前通知”，等待系统连接。服务连接后会尝试补读仍保留在通知栏中的支持来源通知。打开清记也会请求恢复连接；不会自动授予权限。
3. 查看最近通知结果和待确认账单。回调/补读次数包含重复补读，识别/补全次数也不代表账单笔数；重复事件由账本去重。
4. 仍无记录时复制“通知诊断”反馈。它区分未连接、没有收到、空正文、普通聊天过滤、非交易内容、分组汇总、待核实或已识别。内容只包含版本、连接状态、字段名称、字符数、结果代码和计数，不包含原始通知标题、正文、金额、商家或订单号。

已清除的历史通知无法从当前通知栏补读；微信/支付宝可用账单导入补齐。学校账单导入格式尚未适配，可手动补记。诊断能缩小故障范围，不代表已证明小米Android16上的具体根因。

1.5.0支持从通知标题、副标题、会话标题及消息样式的发送方查找微信支付服务标识，读取标准正文、展开正文、文本行与消息条目。普通聊天仍不会仅因正文出现“微信支付”而入账。成功支付附带优惠券宣传不再被一律丢弃。系统未向监听服务提供的文字无法恢复。

## 选择交我办

1. 设置 → 校园应用 · 交我办 → 选择交我办。
2. 从已安装且有桌面入口的应用中搜索“交我办”，核对名称和包名后选择。应用列表仅用于本机选择，不上传；不需要学校账号或密码。不同学校版本通过实际安装的包名区分。
3. 保持通知使用权开启。所选学校应用的交易通知会尝试生成候选，来源显示“校园 / 交我办”，新记录先待确认，核实后才计入消费。
4. 如果学校应用不发交易通知，可选开启“支付页面识别（实验）”，在交我办手动打开一笔已有消费详情。它只尝试读取系统提供的可访问文字，不会自行登录、查询学校后台、点击付款、截图或读取App私有数据库。
5. 可点“停止采集校园应用”。不删除历史账单；之后不再接收该应用的新候选。更换应用后只采集当前选择的一个校园应用。

校园页面需要消费详情/消费成功等标题、支出或消费类型依据，以及明确标注的消费金额或商户字段。余额不会用作消费金额；金额缺失时提示核对。通知中的充值作为转账类候选，默认不计入消费；页面识别排除充值、退款、转账等非消费模板。

本次未取得真实交我办交易样例，也未连接手机，因此学校版本是否提供通知/文字、字段模板是否匹配仍需验证。学校通知不包含商家、页面不提供文字时，不能凭空还原商家；分类继续使用本地商家规则和关键词推荐，可在确认时修改。

## 更新与备份

本版加密备份格式4包括校园渠道账单、分类和规则，仍可读取格式1至3的旧备份。旧版清记不支持新版备份中的校园渠道，请保留升级前备份。通知/页面权限和所选校园App不进入账本备份，恢复后需重新选择并授权。CSV可导出校园渠道，完整恢复请使用加密备份。
