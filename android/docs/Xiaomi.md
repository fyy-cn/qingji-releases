# 小米17 Pro Max · 安装与7天验证

本说明针对你提供的机型；没有假定你当前的Android/澎湃OS版本。菜单可能随系统升级变化，应用“设置 → 真机诊断信息”会显示本机版本。

## 安装与授权

1. 用手机浏览器打开 https://fyy-cn.github.io/qingji-releases/ 下载APK，按系统提示允许当前浏览器安装。已有清记时直接覆盖更新，不要卸载。也可从交付文件安装。打开清记，先手动补记一笔，确认能保存、修改和查看分析。
2. 进入“清记 → 设置 → 开启通知记账”，阅读范围说明后前往系统通知使用权页面，开启“清记 · 支付通知记账”。
3. 若侧载应用的权限开关受限，按系统提示在清记的应用信息中查看是否有“允许受限设置”。不同系统可能另有确认步骤，以设备实际显示为准；不需要Root。
4. 确保微信、支付宝本身允许发布支付通知，并检查是否隐藏交易内容。清记只能识别系统实际交付的内容。
5. 如果锁屏后漏记，在系统设置搜索“自启动”，允许清记后台自启动；检查清记应用信息中的省电/后台限制。应用内小米提示卡可打开本机应用信息。
6. 设置 → 应用更新 → 允许新版通知提醒。这与通知记账授权不同。后台每天尝试检查新版；小米省电或强制停止应用可能延迟检查，随时可手动检查。

应用内下载完成后，如果系统要求，请允许“清记”安装更新；返回后继续确认系统安装。该权限只为安装你主动选择的新版APK，不需要广泛文件权限。完整说明见 [更新流程](Updates.md)。

小米说明后台自启动需由用户自行设置：[小米开发者文档](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=1624)。这不能保证所有通知均可收到，仍需真机对账。

## 首次验证

使用正常日常消费即可，无需为了测试增加消费：

- 微信、支付宝各覆盖一次成功付款，核对金额、时间、渠道、类别和备注。
- 检查解锁、锁屏、切换支付App后的消费；手机重启后再次检查授权与后续通知。
- 连续同商家同金额消费应是两笔；疑似重复要分别确认，不能只按金额合并。
- 不明确、无金额的候选应进入待确认；未收到通知的交易依靠导入补齐。
- 撤销通知使用权后回到清记，首页与设置应显示未授权，历史账单仍能查看和补记。

## 连续7天对账

每天记录：日期、微信成功消费笔数、支付宝成功消费笔数、自动采集笔数、待确认笔数、导入补齐笔数、支出总额、退款额、差额及原因。

1. 消费后先检查自动采集，不急于导入。记录漏记是否伴随无通知、内容隐藏或后台限制。
2. 从两个渠道导出覆盖当天的个人账单，导入预览，处理异常与待确认。
3. 对齐记账口径：支出、退款分开；充值、提现、还款和普通转账不算消费。转账实际用于消费时手动调整。
4. 逐笔核对，确保导入后金额与笔数一致；同一文件再次选择应提示已导入。
5. 第7天汇总自动采集覆盖率 = 自动正确采集的真实消费笔数 / 支持渠道真实消费总笔数；金额正确率单独计算，不把手动/导入补齐算作自动识别。

## 备份验证

先创建加密备份，再尝试错误口令（应拒绝且不修改原账本）；正确口令应显示备份摘要。确认恢复后，核对账单、分类规则和导入记录。请不要在未备份时卸载应用。

## 1.7.1通知稳定性验证

本版会断线重试，并独立于更新设置进行后台连接检查。安装后打开清记一次，查看设置 → 自动记账中的最近连接检查时间。已有通知使用权无需反复关闭重开。

保持学校和支付应用能正常发通知；允许清记后台自启动，并按本机菜单放宽省电/后台限制。在日常消费中观察锁屏一段时间、切换应用、正常重启后的采集，漏记时先保留系统通知，再查看“后台检查”时间和诊断。后台周期会受系统调度推迟，不能保证每15分钟准点运行；强行停止后需手动打开一次。

本次未连接你的手机，仍需实际锁屏验证；已清除的通知通过账单导入补齐。
