# 分类与备注记账（1.7.0）

记账围绕金额、消费分类和备注。日常界面不再填写或展示商家；地点、用途等想保留的信息都放备注。

## 一笔账单，点一下分类

首页 → 快捷归类，或账单 → 快捷归类 · N笔待归类，集中整理未分类的支出、退款和类型待核实的候选。已忽略、已归类、收入与转账不出现在这里。

每笔卡片显示金额、时间、渠道与已有备注。直接点餐饮、交通等分类；“更多分类”包含全部可用分类，包括自定义分类。还可以按渠道筛选、多选后批量设分类。

待确认记录归类后仍需核实金额、币种、类型和疑似重复。点击“去核实”处理；归类本身不批准交易，不改变消费总额。

## 场景模板

快捷归类 → 管理模板，或设置 → 管理场景模板。只需名称、分类和可选备注。例如“二食堂午餐”：餐饮＋备注“二食堂午餐”。以后对账单套用这个模板即可。

- 名称1至20字，不能重名，最多100个模板。
- 支持新增、编辑、上下排序和删除；删除模板不改变历史账单。
- 提供早餐、午餐、晚餐、食堂、超市、交通常用模板。“添加常用模板”不会重复添加，也不会恢复已删除的分类。
- 套用模板会设置分类，只补空白备注，保留已有备注；不修改金额、时间、类型、渠道或确认状态。
- 批量套模板遵守同样规则。若任何一笔已被修改或归类，整批不写入，刷新后重新选择。
- 记账或核实表单也能选快捷场景；仅预填分类和备注，保存后才写入账单与使用记录，取消不记账。
- 最近使用的三个模板显示在表单中，全部模板仍按自定顺序排列。

自定义分类支持新增、重命名、删除与排序。重命名同步账单和模板；删除后相关账单改为未分类，相关模板需重新选择分类。分类与历史金额可在日、周、月、年分析查看，并点击进入明细。

## 备注、搜索与导出

记账表单中，消费分类和可选备注紧跟金额。账单标题显示分类，备注显示在下方。支持按分类、备注或交易号搜索；当前筛选结果或全部账单均可导出CSV。CSV不再包含商家列。

后续通知或导入继续保留人工选择的分类和备注。没有完整通知的支出仍可通过账单导入或手动补记。

## 升级与数据兼容

已有清记请直接覆盖安装，不要卸载。本版沿用数据库4与备份格式5，不重建数据库。

旧账单和模板的商家字段、旧商家分类规则仍保存在本机和完整加密备份中，供旧数据兼容与导入去重使用，不在日常界面展示；编辑账单、套模板不删除或改写这些历史字段。旧模板中的商家不再填入新账单，需要保留的用途请写到模板备注。

完整加密备份包括账单、分类、模板、顺序和使用记录，兼容备份1至4。恢复格式5时空模板列表也如实恢复；旧备份提供可用常用模板。CSV用于表格查看，完整迁移与历史元数据保留请使用加密备份。

归类和模板均在本机处理，不增加读取权限、截图、定位或联网识别。
