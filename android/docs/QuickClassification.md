# 快捷归类（1.6.0）

通知采集金额与时间后，可以直接选择用途；商家可以留空。模板与批量分类均由你点击使用，不会推测真实商家或自动批准待核实交易。

## 一笔账单，点一下分类

首页出现“账单等你归类”时点击“快捷归类”，或在账单页点击“快捷归类 · N笔待归类”。这里集中展示未分类的支出、退款及交易类型待核实的候选；不展示已忽略记录、已归类账单、收入和充值/转账。

每笔卡片显示金额、时间、渠道和已有商家。点击分类按钮即可归类，“更多分类”包含所有可用分类（包括自定义分类）。商家不填也可以完成分类。

待确认记录只修改分类，原确认状态、缺失金额、币种、交易类型、疑似重复提示和来源都会保留。需要核实的记录请点“去核实”，或打开“待确认N笔”。归类本身不改变消费总额。

## 设置自己的场景模板

快捷归类 → 管理模板，或设置 → 快捷归类 → 管理场景模板。

例如新增“二食堂”：分类选餐饮，商家填二食堂，备注填午餐。以后对账单点“套用场景模板 → 二食堂”，就能补齐分类与空白字段。模板不设置金额、时间、渠道或交易类型。

- 名称必填，1至20字，不能重名，最多100个模板。
- 商家与备注选填。只关心用途时可以建“午餐”模板，只选餐饮、备注午餐，商家留空。
- 支持编辑、删除，用上下箭头排序。删除模板不修改已归类的账单。
- 首次安装和升级提供早餐、午餐、晚餐、食堂、超市、交通模板（只使用未删除的内置分类）。这些模板商家均为空，不会假装读到了商家；“添加常用模板”可以补回，名称或编号相同的不会重复添加。
- 模板只补空白商家与备注，账单已有的商家和备注会保留；分类按你的本次选择修改。套用前请选与实际消费相符的模板。
- 手动记账或核实账单时也能使用快捷场景。选模板只预填表单，点击保存后才写入账单并记录使用时间；取消不会记一笔消费。
- 记账表单显示最近使用的三个模板，全部模板仍按你设置的顺序显示。

自定义分类重命名时会同步模板。删除分类后，相关模板标记“需重新选择分类”，重新编辑后才能套用，避免将账单分到已删除的分类。

## 批量归类

快捷归类 → 批量选择，可以勾选多笔，或按渠道筛选后全选当前列表。点“批量设分类”或“批量套模板”。批量套模板同样只补各笔记录的空白商家和备注，不覆盖已有内容。

选择后如果某笔账单已经被其他操作修改、删除或归类，整批不会写入，会提示刷新后重新选择。后续通知或导入会保留这些人工选择的分类与备注。

## 升级与备份

已有清记请覆盖安装，不要卸载。数据库从3非破坏性迁移至4，新增模板表，原账单、分类顺序、删除状态、商家规则和导入记录保留。

完整加密备份升级至格式5，包括模板名称、商家、分类、备注、顺序、使用次数和最近使用时间，仍能读取格式1至4。恢复新版备份时，空模板列表也会如实恢复；恢复旧备份时会添加可用的常用模板。旧版清记不支持格式5，请保留升级前备份。

CSV继续导出账单，用于表格查看；模板与完整恢复请使用加密备份。所有归类和模板处理均在本机，不新增定位、读取剪贴板、后台提醒或联网识别。
