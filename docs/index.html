GET STARTED

装好这一次，
后续在应用里更新。

适用于 Android 10 及以上。已有旧版清记，直接覆盖安装，保留你的账本和分类规则。

  1. 在手机浏览器下载 APK

    微信内无法下载时，点击右上角菜单，选择在浏览器中打开此页。

  2. 按系统提示确认安装

    如果系统询问，请允许当前浏览器安装此文件。已有清记请覆盖更新；无需卸载。

  3. 允许新版提醒，按需开启记账权限

    打开清记 → 设置 → 应用更新，允许新版通知提醒。支付通知记账需要单独开启“通知使用权”。

  4. 之后打开清记，就会检查新版

    后台每天定期检查一次，时间受省电和网络条件影响；新版发布可能需要几分钟同步。发现新版后，查看说明、下载并确认安装。

    关于记账和隐私。

    能自动记录每一笔支付吗？

    通知识别依赖手机实际收到的通知。支付页面识别为可选实验，默认关闭，需单独手动开启无障碍权限；系统授权范围较大，模板兼容仍需真机验证，新记录先待确认。通知内容隐藏、模板变化或后台限制都可能导致遗漏。请定期导入微信、支付宝账单核对，现金等消费可手动补记。真实支付渠道覆盖仍需逐步验证。

    应用联网会上传我的账本吗？

    更新检查只请求公开版本信息，确认下载后获取 APK，不发送账单、原始支付通知或备份。网络请求会携带常规连接信息，例如 IP 地址。本站没有账号、广告、访问统计脚本或账单上传入口。

    每次更新需要卸载吗？

    请直接覆盖安装，同一包名与签名可保留应用数据。卸载或清除数据会删除本机账本。备份文件请自己妥善保管，忘记口令无法恢复。

    为什么没有立即收到更新通知？

    打开应用会自动检查，后台每天尝试检查一次。手机离线、省电、关闭通知或强制停止应用可能推迟提醒，可以在设置中点击“检查更新”。当前采用定期检查，没有即时推送通道。
